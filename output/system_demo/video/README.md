# 脑因智医概念演示视频

## 成片

`../brain-medical-system-demo-v4.mp4`：18秒，1920×1080，60 fps，H.264，适合插入PPT。无配音或背景音乐。旧版 v1、v2、v3 成片保留未覆盖。

## v4 节点固定与界面重绘

- 颞叶节点固定在同一个可见皮层网格顶点，并作为皮层对象的子对象继承旋转。圆环改为真实三维圆环，一同参与旋转与遮挡；不再将深脑沟中的点无条件显示在最上层。
- `surface-anchors.mjs` 只在初始化时选择锚点，动画中不逐帧重选。导出时对全部1080帧检查节点与锚点的世界坐标偏差、父子关系及三维圆环。
- 界面完全重绘为灰白医疗工作台：统一字体、线性图标、细分隔线、低饱和主按钮、结果面板及报告抽屉。只沿用原图的 fMRI/DTI 示例缩略图，不再用AI整页底图承载界面文字。
- 保留原有9条通路、颜色含义、临床示意数据及18秒时间安排。报告脑图仍取自主模型13.65秒的渲染快照。
- 公开获奖资料的核实范围与设计判断见 `design-references-v4.md`；未观看受访问限制的完整冠军视频，未宣称复刻其PPT。
- `backup-v3/` 保留改版前代码；`qa-v4/` 保存五张关键帧、全帧锚点检查、成片逐帧解码结果和一致性检查。

节点位置是概念映射，尤其丘脑、海马等深部结构的表面显示不代表真实解剖定位。连线保持完整可读，并被裁切在脑轮廓内，不宣称真实纤维束或临床因果结论。

## v3 局部修订

- 删除5条不必要的细背景箭头，保留9条有明确图例的连接。
- 图例与模型共用颜色定义；绿色解释为「次级传播通路（示意）」。节点、箭头及起始脑区圆环均有相应图例。
- 节点通过射线与真实皮层三角网格相交确定位置，球体基部接触皮层。连线随这些表面锚点投影移动，并裁切在脑模型轮廓以内，避免悬空及穿出轮廓。
- 为避免脑沟遮挡造成箭头破碎，连线是可读性优先的表面约束标注，不宣称展示真实解剖纤维束。
- 主图、报告缩略图、结果卡片和报告文字中的「颞叶」使用标准简体字及微软雅黑绘制；仅覆盖4处原底图中的相应词语，不改其他文字。
- 图例及上述文字修正以外，其余界面、卡片、图表、交互、镜头和时间安排均保留。
- `backup-v2/` 保留修改前脚本；`qa-v3/` 保存新版逐像素范围检查、图例一致性检查及箭头轮廓检查。

## v2 局部修订

仅更换主视图的脑网络与报告中的脑网络缩略图。参考用户提供的蓝色脑模型、多色节点及清晰箭头风格，增强方向可读性。原有界面、交互、EEG、卡片、趋势图及时间安排均保留。

- 两处图像使用 `brain-network.mjs` 的同一套节点、标签、颜色和有向边。
- 报告缩略图直接截取主模型在 13.65 秒生成报告时的渲染，不再使用另外一张AI脑图。之后背景模型继续缓慢转动，报告快照保持静止。
- 橙色主通路统一为「颞叶 → 丘脑 → 额叶」，与原界面文字相符。
- 标注位置是概念演示用投影布局，尤其深部结构不是临床解剖定位；不代表真实因果或疗效结论。
- `verify-scope.py` 比较五个关键时刻的原始画面，检查脑区及缩略图之外零像素差异，并核对主通路。
- `backup-v1/` 保存旧版脚本；`qa/` 保存旧版检查图；`qa-v2/` 保存新版检查图及检查结果。

v4由程序绘制的界面、真实三维皮层网格渲染、示例影像缩略图和可控制的界面动画合成。并非图生视频模型输出。所有临床数值、网络连接及患者身份均为概念演示数据，不对应真实患者或验证结果。

## 时间安排

- 0–2.35秒：数据就绪，指针点击开始分析。
- 2.35–9.1秒：模型缓慢转动，扫描光移动，节点及有向连线逐步生成；脑电波形与进度同步变化。
- 9.1–13.85秒：重点通路转为橙色，结果字段依次出现，置信度数值、进度条和趋势图绘制。
- 13.85–18秒：报告预览滑入，背景脑网络保持运动。

## 原始素材与来源

- v4界面：`film-v4.mjs` 直接绘制。四张原AI关键帧仍保留；v4只使用其中的示例影像缩略图。
- 三维皮层：Nilearn所附FreeSurfer fsaverage5左右半球标准pial网格及sulcal depth。来源：https://github.com/nilearn/nilearn/tree/main/nilearn/datasets/data/fsaverage5
- 三维渲染：Three.js 0.180.0。来源：https://threejs.org/
- 网格数据仅用于脑表面外形；本片的演示网络连接为人为设定，不代表该标准模板的测量结果。
- 本模型展示大脑皮层；与原AI概念图的艺术化全脑造型不同。
- `assets/sources.json`记录下载地址；许可证保存于`assets/NILEARN-LICENSE`和`assets/THREE-LICENSE.txt`。

## 修改与重新导出

- `brain-v4.mjs`：当前三维模型、扫描光、固定顶点节点、标签及报告快照。
- `surface-anchors.mjs`：按可见性筛选初始化时的固定表面顶点。
- `surface-network.mjs`：绑定表面锚点并受脑轮廓约束的连接、方向箭头及流光。
- `brain-network.mjs`：两处图像共用的概念脑网络定义。`brain.mjs` 保留旧版。
- `film-v4.mjs`：重绘界面、鼠标、波形、进度、图表和报告。`film.mjs` 与 `index.html` 保留v3。
- `render.mjs`：使用本机Edge无界面渲染，经FFmpeg输出MP4。
- `prepare-mesh.py`：GIFTI转换及三角面方向校正。
- `verify-video.py`：逐帧解码检查分辨率、帧率、黑帧及重复帧。
- `verify-v4.mjs`：检查固定节点、三维圆环、图例/网络不变、主图与报告来源及成片验证结果。
